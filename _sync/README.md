# _sync — HackMD 同步工具

本機的 .md 是正本，HackMD 是發佈端。所有操作都以 `HackMD同步對照表.xlsx` 為準。

## 雙擊就能用

| 檔案 | 做什麼 | 什麼時候用 |
|---|---|---|
| `同步.bat` | 處理動作欄（新增／更新／刪除），完成後重建四本目錄 | 日常：寫完新文、改完標籤、要刪文 |
| `只跑新增.bat` | 只處理動作欄是「新增」的列 | 只新增一兩篇，不想讓整表重推一遍 |
| `只重建目錄.bat` | 只依表格順序重建目錄，不處理動作欄 | 調整過文章順序 |
| `推送內文.bat` | 把本機內文推上去，不碰標籤也不改表格 | 改過排版、要重推內文 |

跑之前請先把 Excel 存檔並關掉。

## 對照表欄位

`書 / 章節 / 分區 / 顯示標題 / 檔案路徑 / 動作 / HackMD網址 / 標籤 / 資料夾`

- 動作留空＝這次不處理；填「新增」「更新」「刪除」才會動到那一列
- 處理完會把網址寫回表格、把動作欄清空
- 每次執行前會自動備份一份到 `backup/`

## 推送內文的清單檔

`推送內文.bat` 會找同資料夾的 `推送清單.txt`：

- **有這個檔** → 只推清單裡列到的篇
- **沒有這個檔** → 整表全推（線上長度跟本機一樣的會跳過，不會重複寫）

清單格式是一行一個檔案路徑，跟對照表「檔案路徑」欄一字不差：

```
ORIGINAL/Aegir Marinus/Aegir/01_Aegir 0.0.0.md
FANFIC/まほやく/04_避孕藥.md
```

中途可以直接關視窗，進度記在 `推送進度.txt`，下次會從斷點接著跑。
要重頭跑就把 `推送進度.txt` 清空或刪掉。失敗的會列進 `推送失敗.txt`。

## HackMD API 的兩個坑（2026-09 實測，官方文件沒寫）

1. **PATCH 不能同時送 `content` 和 `tags`**，標籤會寫進去但**內文會被清空**。
   只送 `tags` 也一樣會清空內文。所以順序固定「先 tags、後 content」，分兩次送。
   這個坑在 2026-09-20 造成 436 篇內文全毀。
2. **PATCH 回 202 只代表「收到」，不代表已寫入。**
   每次寫入後都要 `GET` 回來比對長度，不符就重送。

另外：速率限制是 5 分鐘 100 次，實測每篇間隔 7.5 秒才穩。
**要推的篇不能在瀏覽器開著**——HackMD 編輯器會把舊狀態同步回去，把剛推上去的蓋掉。

## 檔案

- `sync_hackmd.py` — 主程式（新增／更新／刪除＋重建目錄）
- `push_content.py` — 只推內文
- `HackMD同步對照表.xlsx` — 唯一的資料來源
- `backup/` — 對照表的自動備份，只留最近幾份
- `deleted/` — 刪掉的文章會先搬來這裡
- `.目錄快取/` — 目錄內容快取，沒變動就不重推
