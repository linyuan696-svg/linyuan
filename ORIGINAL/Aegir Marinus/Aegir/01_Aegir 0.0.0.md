# Aegir 0.0.0

假如無人聽見一棵林中樹倒下，那它究竟有沒有發出聲音？

　　老舊收音機的破爛揚聲器讓主播甜美的聲音都顯得粗啞起來。

　　幸好充滿雜質的聲音並不妨礙內容優劣，主播預告了一個好消息，接下來一週天氣都將晴空萬里。

　　亞格爾心情很好，他甚至哼起歌來。

　　這個小小的平房是他用了最後的積蓄買下的——是的，流浪了這麼久他總算也是存上一點小錢——，他撥了撥左耳垂，手指卻落了個空，這麼多年了他還是沒習慣此處摸不到安神的涼意。

　　今天天氣也很好，他又想起自己隱藏的諸多秘密，事到如今他也是可以隨興地笑了。

　　他彈指，水氣湧上，元素們和他抱怨那些他們曾經分別的時光，亞格爾帶著歉意地散出更多魔力，把風也喚來。

　　他身無長物，就只剩下這些元素們如影隨形。

　　但他知道，那些元素實則從來不存在。

　　凡妮莎給的糖果，效果淵遠流長。

　　而他的心魔最後還是只能由自己親自赦免其罪。

　　買下這間平房的理由也很簡單，除了價格之外，亞格爾幾乎是一眼就愛上了這個採光極佳的空間，靠上的窗戶延伸到屋頂，恍若教堂的穹頂一樣，把空間的顏色塗抹得神聖起來。

　　他隨意落座，享受陽光和風聲輕晃。

　　若是有誰找來，他會放棄這個蓄謀已久的計畫。

　　但在這個明亮到晃眼的房間裡，他從一數到十，又從十數回一，最後叫喚他的只有元素的聲音。
