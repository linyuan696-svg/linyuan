# 黑手黨什麼的有淨灘活動不是正常的嗎？

<style>
.markdown-body p, #doc p, .ui-content p {
  line-height: 2.1 !important;
  margin-bottom: 1.8em !important;
}
</style>

&emsp;&emsp;「Boss，對面的人來了哦。」綁著高馬尾的女子這麼說，拿著手鏡用小指描摹自己的唇型，末了還對鏡子裡的倒影微笑。
&emsp;&emsp;「嗯。」粉色頭髮的男人只是抬眼一瞥，都是老相識了，要說起身恭迎未免多餘，平常裝腔作勢的皮草被隨意放到一旁，養在水族箱裏面的水母好奇地碰觸玻璃魚缸，卻怎麼也碰不到皮草的觸感。

&emsp;&emsp;來者信步閒庭，不知者還以為是在自家後院閒晃，可另一邊緊戒的人員個個自動將腰間的槍給上了膛。少年見狀，正想先來點下馬威，只剛動作就被扯痛了纖細的頸項。
&emsp;&emsp;徐熤舉起左手，繞在手上的皮繩被牽連著，被束縛的人就被扯著跌進他的懷裡。
&emsp;&emsp;「所以說，我該教幾次——」徐熤還沒完，右手的鐵鍊聲響就隨之而至，少女用力往長相相同的少年小腿踹去。在場的人對肢體被毆打的悶聲都能清楚判斷，這下不斷也得疼上幾天。
&emsp;&emsp;徐熤正想發難，揪緊了兩手的狗鍊逼得兩人不得不仰頭看他，還沒開口就又一次被打斷。

&emsp;&emsp;「你們跑到我的地盤是為了秀恩愛的話，我可以清一間包廂給你們。」西西歐看上去心情頗差，就這樣癱在椅子上，「還附帶保險套。」
&emsp;&emsp;「如果你是說祈禱室的話，內特和艾爾伯塔還在裡面哦。」亞格爾這麼補充，看在有外人的份上，把那些不合時宜的玩笑都吞進肚子。

&emsp;&emsp;「已經用完了哦。」兩個藍髮的男人走出祈禱室，一樣都是笑著，卻像是天使和惡魔比肩而立一樣形成強烈對比。
&emsp;&emsp;「徐熤，你們來的好晚。」內特這樣說，似乎為這個沉悶的空氣帶來一些輕鬆的流動。
&emsp;&emsp;艾爾伯塔率先彈了個指，卸下左半邊的人員的警戒。
&emsp;&emsp;隨後是西西歐，右半邊的人也隨聲收起槍枝。
&emsp;&emsp;一切都準備就緒之後，黑膚的男人才從祈禱室裡面走出，手上碩大的行李袋隨手就拋給最左邊的下屬。午夜轉頭交代裡頭東西該有的去處，擺手讓下屬先行離開。

&emsp;&emsp;徐熤打了個呵欠，環看四周，扯了嘴角似笑非笑。
&emsp;&emsp;「人都到齊了，那我們就走吧。」
&emsp;&emsp;「畢竟不想在大太陽底下淨灘，還是快去快回吧。」亞格爾下了結論，踩著恨天高的鞋子往外走去。
