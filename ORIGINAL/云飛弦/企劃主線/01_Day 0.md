# Day 0

&emsp;&emsp;他睜開眼睛的時候意識是一片空白。

&emsp;&emsp;而後才慢慢地、恍惚地、沉沉地想起，今天便是第七日了。

&emsp;&emsp;是靈魂也定然就此停歇的安息日。

---

&emsp;&emsp;那日他不過是隨手又折了一隻紙蝶，本以為會歪斜著落地的魔法這回竟在一種近乎遲疑的延續裡，翩然飛出窗框。在紫霞中歪歪扭扭往鎮上飛去，紅色精靈忍不住好奇，跟隨著往前幾步，視線越過小徑就看見男人的身影。

&emsp;&emsp;要說熟悉，其實對方的裝扮過了百年已經不同，文明進步的太快了，對方適應環境的速度同樣迅速；要說陌生，云飛弦著實沒忘懷過對方一星半點。若腦海中的景象是一張相紙，那必然已經被反覆摩娑到捲起了毛邊。

&emsp;&emsp;而在理智知道如何應對之前，身體已先一步有了反應。

&emsp;&emsp;紙蝶在幾個呼吸間已經靠近吉井，隨後被男人隨手揮落。接著是云飛弦自己，紅色的精靈奔向他的攻擊手段也被輕易壓制，如想像的那樣，吉井不過是伸手押著他的額頭，他便再無法向前半步。

&emsp;&emsp;云飛弦氣惱著，百年光陰過去，自己還沒找到對抗對方的方法，只能像個孩子一樣，試著伸手要撓，伸腳去踢，滑稽的動作磨光了男人最後的耐心。

&emsp;&emsp;吉井終究鬆開了手，順手拎起云的後領，將他提直了，讓他別再胡鬧－－竟還真的奏效，暴躁的精靈果真安靜下來站好。

&emsp;&emsp;「你怎麼在這？」他們最後一次見面已是百年前，但暗夜的眷族對這個詛咒之子記憶深刻，那時任務到了終點，精靈受傷的質問恍若他做了什麼天理難容的決定，實際上，他不過是做了人類社會認定的事情罷，「回報完任務你就不見了，還以為你回去你那個鄉下精靈村了。」

&emsp;&emsp;他原想著這樣也好，始終未曾被文明馴化、無法理解世事運作的生物根本不適合在外面亂跑，也許哪天就會死掉也說不定。真要算起來雖然是任務所迫，但帶著他離鄉背井畢竟也有自己一份，若這隻精靈真的餓死在世界的某個縫隙裡，自己終究得背負起那一絲極其微薄、卻無法徹底卸下的罪愆。

&emsp;&emsp;吉井筑恨透自己這樣多餘的性格。

&emsp;&emsp;精靈本想拒絕回答，但看著對方的臉，終究是扳著臉說他在這裡種田，聲音還是那樣柔軟，百年未變。吉井也許沒發現也許不在乎，這股怒氣下的委屈卻來的更加洶湧。被咬破外層甜膩糖殼的整人糖一下子湧上又酸又苦的氣味，淹沒了不知如何處理情緒的靈魂。

&emsp;&emsp;最後他把問題限縮到剛剛發生的事情。

&emsp;&emsp;「你弄壞了我的蝴蝶。」

&emsp;&emsp;被拍落的紙蝶還在地上，吉井筑猝不及防又被對方跳脫的問題給拉回百年前，好像這個人始終未變一樣，讓人哭笑不得，「你沒事對我放什麼小孩用的通訊法術？」

&emsp;&emsp;終究共處過一年，他稍微想了一下就知道癥結點，「你玩幾天了？失敗很多次了？」

&emsp;&emsp;「不知道我身上都有反追蹤的禁制，這種東西送不到我身邊？」吉井下定結論。

&emsp;&emsp;「我知道！」云飛弦聽到他的否定，急忙反駁，「而且這次不就成功了。」

&emsp;&emsp;「知道還做，浪費時間。」男人打量了云的裝扮，看來是匆忙追出來的，「沒想到自己會成功吧，你這是踩了甚麼狗屎運撞見我剛好來這裡。」

&emsp;&emsp;「那也是成功了，你弄壞我的蝴蝶要賠我。」

&emsp;&emsp;吉井挑眉，看來百年時間多少在這隻精靈身上磨出一點長進，都能知道什麼叫做賠償了，只可惜邏輯還不行。

&emsp;&emsp;「那本來就是送給我的信，賠你個頭。」他彎腰拾起被自己打落的小東西，大概連主人自己也不曾期待過它能順利抵達，整個過程敷衍得近乎一種隨手棄置，紙蝶裡甚至沒有錄入任何聲音或隻字片語。微薄的魔力像是一陣即將散盡的霧，稍微補充一些，還能拿去給別人使用。

&emsp;&emsp;他將紙蝶展平。乍看之下不過是張尋常的白紙，然而透著微光，紙張纖維裡那獨特的脈絡便露出了端倪。吉井筑凝視著那些隱約的紋理，心底悄悄泛起一陣難以言喻的嘆息，不知該說是命運過於寬厚，抑或是某種嘲弄，每次只要遇見這個紅色的精靈，屬於自己的任務標的物，總會以這種毫無防備的姿態攤開在他眼前。

&emsp;&emsp;「喂，你哪來的珥樢樹葉？」

&emsp;&emsp;「我自己的。」云飛弦馬上反應過來，眼前的吸血鬼跟自己不一樣不會無故問問題，「這次要找的東西？才不給你。」

&emsp;&emsp;男人翻了個白眼，順手敲了精靈的頭一下，自然地阻斷對方無意義的絮聒，他突然覺得對方還不如以前連話都說不清楚的時候，至少安靜。

&emsp;&emsp;他想起資料裡記載過的描述。珥樢樹喜歡音樂跟文學，精靈對樹哼唱幾句大概還行，但若要他寫下能夠餵養出果實的文章，那絕無可能。印象中紅色精靈連拼音都搞不明白，在當年四散的、天馬行空的問題裡也不見他對自己問起要學看字，想來仍不諳此道。

&emsp;&emsp;「你難道不想看你的樹能不能結果嗎？」

&emsp;&emsp;說來可嘆，吉井筑試著用過去慣用的方式投下餌料，如他所預料，精靈的眼睛在那一瞬間亮了一下。但這一次，他沒有像過去那樣立刻毫無戒備地湊上前來，而是在原地停留了半晌。那是一段微小的掙扎，在警惕與渴望之間懸空，最終，他伸出手，輕輕拉住了吉井大衣的衣角。

&emsp;&emsp;那你欠我一次，」云飛弦說，語氣裡帶著某種近乎執拗的認真，「我想要打你一頓。」

&emsp;&emsp;吉井低下頭看了他一眼，聲音裡沒有太多波瀾：「你信不信我直接在這裡揍你？」

&emsp;&emsp;語落，他伸手掐了一把精靈的臉頰。

&emsp;&emsp;一點紅印日落就消退了。
