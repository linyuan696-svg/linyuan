# 雙人舞、瓦爾普吉斯之夜、水晶杯(咪金)

&emsp;&emsp;3 tags：雙人舞、瓦爾普吉斯之夜、水晶杯

&emsp;&emsp;出場人物：咪金

&emsp;&emsp;備註：想看金已經有意識的曖昧中了(?

&emsp;&emsp;你知道嗎？這是一場屬於魔鬼的盛宴。

&emsp;&emsp;春沢描述的活動是金聞所未聞的。在某日夜裡，人們戴著各式各樣的裝扮，混淆善惡之後共舞其中。

&emsp;&emsp;此時他們拿著成對的水晶杯，待在這個小小的鎮上共飲。杯口鑲著一圈很薄的金屬，折射出的光芒卻略顯黯淡。至少在春沢眼裏是這樣的。

&emsp;&emsp;不及眼前精靈臉上的斑斕光彩，也不及杯身折射出的細碎顏色。就是這樣一對杯子，在他們輕碰杯口的時候，所有光線都經過它，被那些切面拆開，又重新拼在一起，最後凝聚成金眸底的灰藍色。

&emsp;&emsp;金恍惚間似乎看到窗外有火，又或許是誰家的火鳳花在夜裡盛放。

&emsp;&emsp;「那這樣不就給了魔鬼傷害人的機會嗎？」不解風情的精靈如是說。

&emsp;&emsp;「大概就像是、啊，聖囂節的時候不是也有貓怪的服飾嗎？我的國家也有類似的事情，」日本的妖怪在頭上比畫出兩個尖角，「為了要把鬼趕出去，所以得有人扮成鬼。」

&emsp;&emsp;「那你呢？」金忽然問，俯身給春沢倒酒。他們指尖相觸，卻未真正緊握。

&emsp;&emsp;「什麼？」鞋側碰到彼此，又驚覺不妥地分開。

&emsp;&emsp;「你扮成什麼？」在轉換杯口的時候差點撞上，近到鼻尖幾乎相觸。

&emsp;&emsp;春沢沒有回答，又喝了一口清澈的酒，「我會負責灑豆子。」

&emsp;&emsp;一切都顛倒過來；鬼在灑豆子，魔鬼在歌唱。

&emsp;&emsp;溫雅的男子紅了臉，忽然伸出手。

&emsp;&emsp;金最後還是將手放了上去，杯子被放在兩人中間，感覺到喉嚨乾啞到近乎鼻酸。

&emsp;&emsp;這原就是一個共同等待春日真正降臨的盛宴。
