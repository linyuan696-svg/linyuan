# 云 0.1.1

&emsp;&emsp;也許是第一次體驗到那樣的矛盾，所以才會那麼委屈。

&emsp;&emsp;但實質上吉井筑只是評估了利益的最大化，合乎所有關於人類的常理。

&emsp;&emsp;他回到家才愉快的放出羔羊，猛然變化的環境讓小羊有些受驚。云飛弦將其放到紅色的草皮上，這邊有設置好的柵欄，可惜柵欄攔不住鴨子，所以裡面暫時並未有其他生物。

&emsp;&emsp;他蹲下來溫柔的撫摸羔羊的頭顱，在看不到其他同類的狀況下，這個生命一頭扎進他的懷裡。

&emsp;&emsp;「啊、你就叫小雲吧，這樣名字跟我很像呢。」

&emsp;&emsp;小羊又是委屈又是依賴的回應，像是聽懂了他的說詞。

&emsp;&emsp;他自認是個很有耐心的人，每天領著羔羊，或是耕作，或是發呆，雨天時會第一時間拿著斗篷來把羊兒接回屋內。

&emsp;&emsp;潔白的羊毛漸漸褪下，他蒐集了一籮筐的羊毛，親手洗淨之後紡成毛線。

&emsp;&emsp;那毛線被紡成大大的一球，比其他羔羊產出的都要更多。白色的毛逐漸成為灰色的時候，云飛弦養成了新的習慣。

&emsp;&emsp;例如他會在田間嚇唬他純潔的小動物，看著兩個月大的孩子嚇得噴水，濕潤田間的作物。

&emsp;&emsp;他對此開心的笑彎眼，在嚇唬對方之後，又俯身溫柔地撫摸小雲，柔軟的毛髮比其他同類稀疏不少。

&emsp;&emsp;「寶貝，別害怕，我在這呢。」

&emsp;&emsp;他在小雲的耳邊輕哼，柔軟的聲音像是捕夢網，網羅著誰的恐慌不安。

&emsp;&emsp;「我給你唱歌吧，是之前旅行的時候聽過的歌。」

&emsp;&emsp;啊，褪盡知更鳥可憐的羽毛。

&emsp;&emsp;冠藍鴉是否也在笑？

&emsp;&emsp;他把鄉村藍調變了性，唱得繾綣輕柔，一邊撫摸羔羊的毛髮，一邊把臉埋進柔軟的羊毛中，暫停歌唱輕輕咬上一口。

&emsp;&emsp;然後又笑著繼續唱。

&emsp;&emsp;本想將其軀殼盡數吞食，奈何不堪品嘗。

&emsp;&emsp;幸好，小羊在他的照顧下很快茁壯，顏色變得更深的時候，已經不再害怕云飛弦的惡作劇。

&emsp;&emsp;云飛弦撫摸著小雲日漸茁壯的角，在後者全心依賴而純潔的目光中，將其取下。

&emsp;&emsp;隱蔽的魔法能埋藏所有法陣內的痕跡，聲音自然也是被著重處理的訊息之一。

&emsp;&emsp;被刺痛指尖的時候他扳起臉，如往常一樣教育自己的牲畜。

&emsp;&emsp;「不乖哦，要是吵到鄰居就不好了，不可以這樣尖叫。」

&emsp;&emsp;他早先將羊隻的四肢綑綁妥當，剃盡毛髮。約是尚留著一絲毛根，所以儘管已經沒能有蓄電的組織，仍能在恐懼中產出微弱的電流。

&emsp;&emsp;云飛弦想了想，又覺得自己有些矛盾，不免失笑。

&emsp;&emsp;「不對，我已經做好結界了，小雲可以尖叫沒關係，聽說叫出來，就可以忍受更多的痛痛。」

&emsp;&emsp;云飛弦把手按在另一個角上，借助槓桿的力量，和第一次一樣順利取下價值不菲的道具。

&emsp;&emsp;「因為你是我的寶貝。」

&emsp;&emsp;他血紅色的眼睛認真承諾，親吻純潔羊隻的額頭，如同過去三個月每天做的那樣。

&emsp;&emsp;「好了，聽說布告欄上面有人說需要羊毛呢。」
