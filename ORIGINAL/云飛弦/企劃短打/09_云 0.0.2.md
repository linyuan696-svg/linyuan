# 云 0.0.2

&emsp;&emsp;今年001-4號田裡鴨子從來不超過三隻。

&emsp;&emsp;也從來不少於一隻。

&emsp;&emsp;蜜蜂們飛過那片田時，沒有聞到花蜜以外的氣味。

&emsp;&emsp;還聽到了聲音。

&emsp;&emsp;那是一種很奇怪的聲音，藏在花瓣裡，藏在泥土下面，像有許多細小的生命隔著很遠很遠的地方低語。

&emsp;&emsp;001-4號田裡種滿了暖色的花。

&emsp;&emsp;有些花開起來像火，有些花在風裡搖晃時，會發出不像植物能發出的聲音。

&emsp;&emsp;蜜蜂們並不在意。

&emsp;&emsp;牠只知道，田裡的鴨子沒有聲音。

&emsp;&emsp;牠們會張嘴，會拍動翅膀。

&emsp;&emsp;會在紅色精靈靠近時仰頭。

&emsp;&emsp;但牠們不會祈禱，以泰坦之名。

&emsp;&emsp;紅色精靈住在田裡。

&emsp;&emsp;他不像森林裡流傳的精靈那樣美麗，也不像人類故事裡那樣寡欲。

&emsp;&emsp;他會在月色中歌唱，然後把失去聲音的生命留在花田裡。

&emsp;&emsp;蜜蜂曾經沿著田前的道路飛行。

&emsp;&emsp;那裡有被挖掘過的痕跡。

&emsp;&emsp;泥土下面埋著許多幼小的骨頭。

&emsp;&emsp;每一具骨頭都讓事件的輪廓十分清晰。

&emsp;&emsp;蜜蜂不知道紅色精靈為什麼這麼做。

&emsp;&emsp;也許沒有原因。

&emsp;&emsp;他們只看見，當紅色精靈帶走新的幼鴨時，所有花朵都開始低語。

&emsp;&emsp;像是在歡迎。

&emsp;&emsp;又像是在哭泣。

&emsp;&emsp;第四塊田裡永遠會有鴨子。

&emsp;&emsp;一隻。

&emsp;&emsp;兩隻。

&emsp;&emsp;或者三隻。

&emsp;&emsp;牠們活著。

&emsp;&emsp;卻沒有聲音。
