# 云 0.1.3

&emsp;&emsp;真的要說的話，云飛弦在遇到吉井筑之前的生活是一片混沌的。如同天地相合的遠古時代，無天地之分；善惡之別。

&emsp;&emsp;世界是什麼時候悄悄改變的，又或者生物是何時睜眼看見這個世界真實的樣貌。

&emsp;&emsp;是那一年的任務中，吉井筑為了方便灌輸了他所謂社會運作的規則。

&emsp;&emsp;我不能切開那個東西的喉嚨嗎？

&emsp;&emsp;那樣血噴的到處都是很不衛生。

&emsp;&emsp;我要一直戴著隱蔽的法術？

&emsp;&emsp;你不知道我多帶你一個有多麻煩嗎，給我藏好點。

&emsp;&emsp;我想要去那邊。

&emsp;&emsp;你要跟我在一起行動只能聽我的。

&emsp;&emsp;那個寶寶不是帶著詛咒嗎，不拿掉嗎？

&emsp;&emsp;對方付錢——不，不管什麼時候殺掉幼小的生命大家都不會輕易接受的吧。

&emsp;&emsp;大家不是不會接受殺掉寶寶嗎？

&emsp;&emsp;那是個受到詛咒的東西，現在他已經不是寶寶了。

&emsp;&emsp;云飛弦記得他那天在河裡洗著被擦到髮上的血，糾結成一塊的紅色頭髮被一次次清洗，淡橘色流去的汙水是血液融入水中的樣子。

&emsp;&emsp;為什麼血明明顏色那樣鮮豔，跟水混合之後卻不是淺紅色呢？

&emsp;&emsp;被詛咒是什麼呢，若是生來就是禁忌，那也是詛咒嗎？

&emsp;&emsp;吸血鬼這種東西，不就是能夠行動的屍體嗎？談何人性進而殺人呢？

&emsp;&emsp;太多疑問混雜，紅色的精靈想不透。

&emsp;&emsp;天地分開了，世間有了善惡之分。

&emsp;&emsp;他把重新編織好的織夢網掛在窗口，他要編織什麼樣的夢呢？

&emsp;&emsp;聵然無知的夢，殺死吉井筑的夢，又或者如同普通精靈生活在村落裡，在豐年祭踏著鈴聲起舞？

&emsp;&emsp;他突然想起剛來鎮上的時候，似乎是燒了很多土旱子，五顏六色的火焰在生物內部壓力過高的時候一口氣爆開，省略了磨成粉的工序，還能看到昆蟲有趣的扭動，讓他為此著迷好些時日。

&emsp;&emsp;還有那隻羊，叫什麼名字來著，對了，小雲。

&emsp;&emsp;那雙如墨的眼睛，像是多年前那個出生的嫩嬰一樣，乾淨的只能反映出恐懼。

&emsp;&emsp;從天空開始吧，比起日光，他更喜歡月亮。他著迷於月亮輪廓邊緣，那個無星漆黑的墨色地帶。

&emsp;&emsp;純淨生物眼中的驚懼，還有不受意識控制的扭動感。

&emsp;&emsp;云飛弦勾起微笑，抱好自己的枕頭。

&emsp;&emsp;那就勉為其難的讓吉井筑也出現在自己的夢裡吧，他並不討厭那個菸草味道。

&emsp;&emsp;甚至是喜歡對方充滿惡意又淺嘗即止的嘴，夢裡他會說什麼呢。

&emsp;&emsp;他說，你讓人覺得很噁心。

&emsp;&emsp;墜入夢鄉的瞬間並不是下墜，而是往上，那樣的幸福感如同愛戀。

&emsp;&emsp;那為何使用墜入這個字呢？

&emsp;&emsp;那是因為天地相合，世間本無善惡之分。
