# 云 0.0.0

&emsp;&emsp;云飛弦一直覺得吉井筑是一個月亮一樣的存在，穿過葉尖灑落的光讓他隱約窺見巨木的輪廓，他努力仰著頭，多少也被那些亮光照拂些許。

&emsp;&emsp;他們有過一段無以名狀的時光，他在路上教會他些許魔法－－或有嘲諷－－，八成時間都算相安無事，相互合作。還有他第一次做愛，以及爭吵。

&emsp;&emsp;要跟外人闡述的話，只能說他們曾經共行過一段路。

&emsp;&emsp;對他來說，吉井筑跟其他生物是不一樣的。

&emsp;&emsp;那件披風裹挾的菸草氣味經過百年仍經久不散。

&emsp;&emsp;直到某一天，云飛弦路過這裡。

&emsp;&emsp;據說十年前有過一次地形變動，而後生命在這裡建立全新的規則。

&emsp;&emsp;在長生種族面前，人類變革的速度總讓人驚嘆不已，換作是他的老家，也許此時還在慢悠悠地清理土地賜予的粉塵，不似眼前的鎮落已經煥然一新。

&emsp;&emsp;所以他掏出那個破舊的皮袋，拿出部分金幣登記落腳的方式。

&emsp;&emsp;農夫嗎？

&emsp;&emsp;「沒有問題，我在我老家也會種些精靈草藥。」雖然由於他的天性，那些藥草總是奄奄一息，但總體來說還算是獲得族長的認證。

&emsp;&emsp;他聽著鎮上員工地說明，收下對方遞過來的證件。

&emsp;&emsp;意外地聽見他很久沒聽過的祝福。

&emsp;&emsp;Adimisite。

&emsp;&emsp;云飛弦難得偏過頭再次看了一眼招牌，露出乖巧柔軟的表情回以祝福。

&emsp;&emsp;「芬葛里在上，Adimisite。」
