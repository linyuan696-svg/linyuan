# 云 0.1.4

&emsp;&emsp;極度厭惡的時候，胃酸翻湧的時候，若非生來有智的話是不會有如此明顯的矛盾拉扯，對野蠻的生命來說，排斥就會只是純粹的排斥。可偏偏不光是知道抗拒而已，會發熱，會泥足深陷。即使只能透過最不堪的交纏出現，那股赤裸的慾念還是在某個陰暗的角落活著，然後一次又一次地在這裡展現出不該有的、無法被理智馴服的原始渴求。

&emsp;&emsp;兩打六花蝶猶嫌不足，花了三隻幼鴨才把他們餵養到成熟，云飛弦吮了口結痂的指尖，神色淡漠的坐在蛹前，等待他們破殼，展翅。

&emsp;&emsp;展翅時就能取下。

&emsp;&emsp;手感微涼，還帶著些許將乾未乾的黏液，半透明的蝶翼被精靈小心翼翼的去其翅面留其脈絡，完整剔了十隻蝴蝶，他才滿意地抹去額角不存在的虛汗。

&emsp;&emsp;鎮長先生的紙條被他記在心裡，就算是作為對方送他一把傘的回禮，讓他動了這個念頭。說不清是因為煙的緣故，還是荊棘的關係。回想起來，那一天早已失去了完整的形狀，只剩下幾個片段彼此依附，像雨滴墜地時四散的水花。

&emsp;&emsp;被他擲出的水雨傘破碎成一朵倉促綻放的花，而花朵總是得伴隨蝴蝶。

&emsp;&emsp;如同光總要找到眼睛，缺一不可。

&emsp;&emsp;小禮帽頭飾的製作法談不上困難，首先得有個支撐底座，形狀隨意，其次堆疊上些網紗，像把空氣慢慢折進布裡，再以指尖將它盤出一個勉強能夠相信的輪廓就可以加上裝飾。

&emsp;&emsp;將六花蝶的骨骸拆解、梳理，再與絲線反覆交錯，編成近似蕾絲的網紗，它既不是布，也不是骨，更像介於兩者之間，一種仍然記得飛行的質地。

&emsp;&emsp;最後當然要在最醒目的位置綴上一隻完整的六花蝶。

&emsp;&emsp;但不是標本，而是被停止時間的生命。

&emsp;&emsp;將亡未亡的蝴蝶動彈不得，時間在牠振翅之前被縫合，死亡尚未抵達，生命也無法離開，只得被極細的針腳固定在飾品中央。

&emsp;&emsp;涼冷的氣息會延續到三日後，暫停時間的生命沒辦法超越既有的命運軌道，是以只能存活三個月亮天的蝶自然也無法帶來第四日的涼爽，他得趕快送出這份委託。

&emsp;&emsp;匆匆出門的時候他又看到剩餘的蠟燭材料，那股隱約的竹香又蔓延開來。

&emsp;&emsp;原來慾望並不站在喜歡那一邊。它甚至可以依附在憎惡之上，像傷口反覆結痂又撕裂，不曾癒合，也不曾停止生長。
