# 云 0.0.1

&emsp;&emsp;過去二十年間，云飛弦一直重複做著同一個夢。

&emsp;&emsp;第二天形容憔悴的時候，若被問起昨夜是否安好，他也只能撓著臉想了想說做了一個驅車前往山窮水盡之處的夢。

&emsp;&emsp;有些人或說是個好預兆，也有些人提供給他安神的配方，然後轉而推銷起他不曾看過的產品，所幸他不再是那個予取予求的無知者，得以裝傻充愣的敷衍過去。

&emsp;&emsp;但其實並不是這樣的。

&emsp;&emsp;並不是他主動驅車，而是被牽著走往那處，隱約的不安在夢裡被放大。

&emsp;&emsp;他自己心裏清楚，並不全是夢，而是過去不斷循環重複。

&emsp;&emsp;偶爾他躺在床上感覺不到時間的流逝，看見斜映進新居的日光，才想起他現在有其他任務在身。

&emsp;&emsp;於是他慢吞吞地在日落時分來到田間，彈指就翻好幾些土壤。

&emsp;&emsp;把濾起的長條節肢動物放入口袋，他拿著小土耙蹲著，一邊耙土一邊等待月亮升起。

&emsp;&emsp;這是距離城鎮最近的一塊土地之一，像是跟過去賭氣似的，儘管他並不喜歡和誰交流，但他就是在選地的時候想起那男人說過的話。

&emsp;&emsp;『每有新的生命降臨，蠢精靈們大概都會聚在一起歌頌，你總是事後才被告知，每個要為大地獻上祝福的豐年祭典，你頂多也就在邊緣瞎忙，或被叫去遠方幹些雜活吧。』

&emsp;&emsp;對話提及的場景的確歷歷在目，但那都是有相當明確又合理的理由的，吉井不過是跟平常一樣又在盡其所能地揶揄他，云飛弦想反駁，卻又一時半刻想不到一個有力的說法。

&emsp;&emsp;『我告訴你原因吧。』吉井眼帶笑意，帶著邪惡的氣質的眼尾有些勾人。

&emsp;&emsp;『因為紅色的眼睛真的有夠噁。』

&emsp;&emsp;才不是。

&emsp;&emsp;云飛弦選了這塊土地，看著隱約可見燈火的城鎮。

&emsp;&emsp;眾人眼中的禁忌之子，在他眼裡卻只是自己的同類。誰說所有生命都是純潔的，又有誰說當時孕婦產下的人子天然邪惡。

&emsp;&emsp;輿論的矛頭一轉，吉井筑就了結了那對母子的生機。

&emsp;&emsp;不是這樣的，這樣是矛盾的。

&emsp;&emsp;云飛弦睜大眼，在夢裡這樣說：你說在生命帶來罪惡前，人們都是寬容的，因為生命天然是純潔的。

&emsp;&emsp;吉井嗤笑著甩乾短刀上的血漬：你看看周圍的人吧，他們如今已經是邪惡本身。

&emsp;&emsp;男人低下頭，壞心的把甩不去的體液擦在他的頭髮上。

&emsp;&emsp;跟你一樣，白癡。

&emsp;&emsp;云飛弦好像氣得咬了吉井英俊的下巴，然後醒來發現自己擰著棉被咬著布角。

&emsp;&emsp;才不是。

&emsp;&emsp;他並非無權存活在世間之人。

&emsp;&emsp;他抹抹臉頰上的口水，哼地起床。

&emsp;&emsp;因為吉井明明也是邪惡的，這個城鎮也是。

&emsp;&emsp;生命並非天然純潔，但邪惡也不該被提前扼殺。

&emsp;&emsp;是這樣的，吉井筑。
