# 云 0.2.3

&emsp;&emsp;月光把乾涸的紅草地照得像一片結痂的傷口。

&emsp;&emsp;云飛弦蹲在田埂間，微涼的手指輕柔地撥開枯死的無常樹根系。那裡正蜷曲著幾條肥美的旱地子。因為土地被牠們吸吮得太過乾渴，這幾隻小東西正神經質地在泥沙中蠕動。

&emsp;&emsp;他把珍貴的生命捧起放入瓶子中，按照顏色分類，讓人意外的是，這些生物顏色遠比書本上記錄的更多，似乎會因為食用的土壤而有所差異，他心情很好的在各個玻璃罐中放入不同顏色的旱地子，在裡面撒上土壤，讓蟲子在裡面盡情翻滾。

&emsp;&emsp;精靈天生是擅長與天地溝通，他可以輕易分辨土壤是否需要更多水分；這些蟲子是否因為無聊而感到不悅。雖然他們不會說話，但傾聽自然的聲響總是最好的生存方式。很久之後他曾試著把這樣的生活方式分享給紅色外星人，雖然成效不彰，但總算是初次組織了描述他生命的語言。

&emsp;&emsp;自從某次意外把蟲子丟進火中，他就知道這些生命可以迸發多美麗的色彩。

&emsp;&emsp;他試了很多次，用各種結界，才讓焰火的爆炸達到最大化。

&emsp;&emsp;空氣是主要關鍵，最好的爆炸方法就是隔絕掉所有空氣直到真空狀態，生物的內部壓力會因此齊齊向外，砰地炸開來。

&emsp;&emsp;但沒有空氣的話火焰無法持續燃燒，所以他試了兩三個月，才終於意識到無法從外部環境著手，那就往內部加壓。

&emsp;&emsp;未來的朋友將會告訴他這個原理叫做微波，但此時的云飛弦只是單純地用魔力去震動生物體內的元素，直至體內的壓力抵達臨界，然後成為一朵炫麗的花。

&emsp;&emsp;他總是溫柔的耙著土，細細找到更多旱地子。

&emsp;&emsp;原本仔細分類的瓶瓶罐罐因為粗心，逐漸減少分類；今天打破了一個瓶子，明天把顏色放錯乾脆整合兩個罐子。

&emsp;&emsp;到了最後，他挖遍自己的田，也找不到一隻旱地子了。

&emsp;&emsp;「沒意思。」

&emsp;&emsp;孩子的興趣來得快，去得也快，短短一年間他就找不到更多可以被圈養的蟲，逐漸轉移的注意力讓他忘了僅剩的最後一個罐子，原本是數百條旱地子被他存著，要給自己辦一場小型的花火秀的。

&emsp;&emsp;最先消失的是白色，爾後是黑色。

&emsp;&emsp;最後消失的是一條傷痕累累的紅色旱地子，然後僅存的那條，沒人能說出那是什麼樣的色彩。

&emsp;&emsp;發瘋的生命被關在透明的牢籠裡面尖叫，吞食自己的同類，蠕動，然後幾近死亡。

&emsp;&emsp;後來紅色的精靈從廚房翻找著鍋具的時候，才又看到這個瓶口生鏽的玻璃罐。

&emsp;&emsp;他困惑著自己怎麼會持有這種東西，但很快把疑問拋諸腦後。

&emsp;&emsp;「正好可以拿去擺攤。」云飛弦打開蓋子，補了一點沾著鴨子血水的土進去，奄奄一息的旱地子重獲新生，黯淡的色彩變得更加飽和。

&emsp;&emsp;紅色的精靈最近心情好得驚人，帶著準備好的驚喜去參加市集，小小的惡作劇總是會讓自己覺得開心。
